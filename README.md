# Portal de Manuais — Tennis Place

Publicação oficial: https://tennisplacebrasil.github.io/manuais-loja/

Este repositório contém exclusivamente a interface do Portal de Manuais, seus recursos de acesso, favicon e ajuda do Tepê.

O arquivo index.html é a entrada principal e mantém o endereço /manuais-loja/. Os logins, permissões e conteúdos protegidos utilizam o serviço Supabase já existente. Os portais e cada manual são carregados somente quando selecionados, com cache limitado à memória da sessão e validação de acesso no servidor.

GitHub Pages: branch main, pasta / (root). Sem domínio personalizado. Sem etapa de compilação.

As alterações neste repositório são independentes das cópias existentes no repositório do Hub.
